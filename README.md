# Каталог вопросов ORT+

Центральный каталог публичных наборов вопросов. Файл `catalog.json` содержит
двуязычные описания и ссылки на `manifest.json` каждого набора.

Адрес для сборки приложения:
`https://raw.githubusercontent.com/Umar151515/ORT-Catalog/main/catalog.json`

Обновление существующего набора меняет его `manifest.json`, а не этот каталог.
Новый набор добавляется отдельной записью. Токены и авторизация не требуются.
Публикуйте каталог после размещения манифестов и архивов обоих наборов.
